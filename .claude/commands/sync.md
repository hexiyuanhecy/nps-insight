# 同步数据

## 执行步骤

1. 读取 `.env` 获取飞书配置
2. 确认 BITABLE_URL 格式正确 (应为 `https://www.feishu.cn/base/{app_token}`)
3. 读取「系统配置」多维表格，解析配置项:
   - Tag1 固定列表
   - Tag2 初始化配置
   - 大租户列表
   - 权重配置 (数量、大租户、质量)
   - Bot 群 ID
   - 周报/月报文档 ID
4. 读取「标签库」多维表格，解析所有 Tag2 和 Tag3
5. 检测标签状态 (正常、待确认、已废弃)
6. 将同步的配置写入系统配置存储

## 输出格式

```
## 数据同步完成 ✅

### 同步的配置
- Tag1 数量: X 个
- Tag2 数量: X 个
- Tag3 数量: X 个
- 大租户: X 个
- 权重配置: 数量=X, 大租户=X, 质量=X

### 标签统计
- 正常标签: X 个
- 待确认标签: X 个
- 废弃标签: X 个
```

## 注意事项

- 如多维表格访问失败，检查 URL 格式和网络连接
- 如配置为空，保持使用默认值
- 同步后建议验证配置是否生效
