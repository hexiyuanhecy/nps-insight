# NPS Insight 测试文档

**版本**：v2.0
**测试范围**：完整分析周期（2次数据拉取打标 + 1次月度分析 + 标签自进化）
**测试工具**：Playwright MCP 浏览器自动化
**基准**：PRD v2 + tech-v2 + 2026-06-22 代码审查决策

---

## 1. 测试环境准备

### 1.1 前置条件
- 飞书自建应用已创建，App ID、App Secret 可用
- 飞书测试群已创建，Bot已加入群聊
- 飞书多维表格 API 权限已开通
- 测试用 LLM API Key 可用（AgnesAI）

### 1.2 测试数据说明
- 每次数据拉取 Mock **200条**反馈
- 数据包含：
  - 评分分布：1分约20%，2-3分约50%，4-5分约30%
  - 集中问题：至少20%反馈指向同一类问题（如“打卡定位失败”）
  - 租户覆盖：A1-A6全覆盖，大租户(A4/A5/A6)占30%
  - 平台覆盖：小程序打卡、小程序统计、Web、iOS、Android
  - 不满意原因覆盖：系统卡顿、界面不美观、功能缺失、打开速度慢、其他、缺少功能
- 反馈时间范围：测试周期内随机分布
