## 1. 产品定位

NPS Insight 是一款基于飞书多维表格的 AI 用户反馈分析工具。AI 自动拉取数据、打标签、生成图表与报告；人工在表格中审核标签，基于统计结果推动问题解决。

**核心原则**：
- 一条反馈可能同时包含多个问题，标签均支持多选。
- 反馈列表中的标签全部从标签体系表**引用**，不存文本。
- 租户信息**按需自动补充**，仅当出现新租户时才新增。
- 不同用户的配置和数据**完全隔离**，敏感信息加密存储。

## 2. 用户与权限

### 2.1 用户识别
使用飞书用户 ID 作为唯一标识。在飞书应用内自动获取身份，浏览器访问则通过飞书 OAuth 登录后获取，无需额外注册。

### 2.2 角色与权限

| 角色 | 权限 |
|------|------|
| **配置所有者** | 首次创建配置的人。可修改所有配置项，包括增删管理员 |
| **管理员** | 可修改除"管理员列表"外的所有配置项 |

## 3. 数据存储设计

所有数据存储在飞书多维表格中，共 6 张数据表。

### 3.1 反馈列表

| 字段 | 类型 | 说明 |
|------|------|------|
| 反馈ID | Text | 唯一标识 |
| 租户ID | Text | 租户唯一标识 |
| 租户名称 | Text | 自动关联租户信息表显示 |
| 租户规模 | SingleSelect | A1-A6 |
| 用户ID | Text | 提交反馈的用户ID |
| 创建时间 | DateTime | 用户提交反馈的时间 |
| 不满意原因 | MultiSelect | 系统卡顿、界面不美观、功能缺失、打开速度慢、其他、缺少功能 |
| 反馈原文 | Text | 用户输入的文字内容 |
| 翻译后文本 | Text | 非中文内容经 AI 翻译后的结果 |
| 评分 | Number | 1-5 分 |
| 反馈平台 | Text | 如小程序打卡、Web 端 |
| **Tag1** | MultiSelect | 引用 Tag1 表（多选） |
| **Tag2** | MultiSelect | 引用 Tag2 表（多选） |
| **Tag3** | MultiSelect | 引用 Tag3 表（多选） |
| AI 置信度 | Number | 0-1 的数值 |
| 需查日志 | Checkbox | 标记是否需要排查日志 |
| 待审核 | Checkbox | 标记是否需要人工复核 |
| 打标状态 | SingleSelect | `未打标` / `已打标` |

### 3.2 标签体系

标签体系分为三张独立子表，每张表均自动统计使用情况。

**Tag1 表（问题性质）**

| 字段 | 类型 | 说明 |
|------|------|------|
| tagId | Text | 唯一标识 |
| 标签名称 | Text | 如"疑似Bug" |
| 定义说明 | Text | 标签的详细解释 |
| 总使用次数 | Formula | 统计引用次数 |
| 大租户使用次数 | Formula | 大租户（A4/A5/A6）引用次数 |
| 大租户占比 | Formula | 大租户使用次数/总使用次数 |
| 平均评分 | Formula | 引用该标签的反馈平均分 |

**默认 7 个 Tag1**：疑似Bug、功能优化、界面改进、性能提升、用户教育、安全合规、无效反馈。

**Tag2 表（功能模块）**

| 字段 | 类型 | 说明 |
|------|------|------|
| tagId | Text | 唯一标识 |
| 标签名称 | Text | 如"打卡模块" |
| 所属一级标签 | Relation | 关联到 Tag1 表（可选） |
| 总使用次数 | Formula | 统计引用次数 |
| 大租户使用次数 | Formula | 大租户引用次数 |
| 大租户占比 | Formula | 大租户使用次数/总使用次数 |
| 平均评分 | Formula | 引用该标签的反馈平均分 |
| 下级 Tag3 数量 | Formula | 关联的 Tag3 数量 |

**Tag3 表（具体问题）**

| 字段 | 类型 | 说明 |
|------|------|------|
| tagId | Text | 唯一标识 |
| 标签名称 | Text | 如"定位失败" |
| 所属二级标签 | Relation | 关联到 Tag2 表（必填） |
| 总使用次数 | Formula | 统计引用次数 |
| 大租户使用次数 | Formula | 大租户引用次数 |
| 大租户占比 | Formula | 大租户使用次数/总使用次数 |
| 平均评分 | Formula | 引用该标签的反馈平均分 |

### 3.3 租户信息表

| 字段 | 类型 | 说明 |
|------|------|------|
| 租户ID | Text | 唯一标识 |
| 租户名称 | Text | 公司/组织名称 |
| 规模 | SingleSelect | A1 - A6 |
| 是否企业版 | Checkbox | 是否为企业版用户 |
| 联系人 | Text | 联系人姓名 |
| 联系邮箱 | Text | 联系邮箱地址 |
| 日志平台 | Text | 日志查询平台地址 |
| 创建时间 | DateTime | 记录创建时间 |

**补充规则**：当反馈列表中出现新租户时，系统自动查询其名称并写入此表。

### 3.4 Top 问题表（周期分析表）

| 字段 | 类型 | 说明 |
|------|------|------|
| 所属模块 | Text | Tag2 名称 |
| 具体问题 | Text | Tag3 名称（逗号分隔） |
| 问题标识 | Text | `tag2Name||tag3Name` |
| 总反馈数 | Number | 累计反馈数 |
| 本周期新增 | Number | 本月新增反馈数 |
| A4反馈数 | Number | A4 规模租户反馈数 |
| A5反馈数 | Number | A5 规模租户反馈数 |
| A6反馈数 | Number | A6 规模租户反馈数 |
| 大租户反馈数 | Number | A4+A5+A6 合计 |
| 大租户占比 | Number | 大租户反馈数÷总反馈数 |
| 平均分 | Number | 相关反馈平均分 |
| 人工综合排序 | Number | 仅供人工填写，系统永不覆盖 |
| 负责人 | Text | 仅供人工填写，系统永不覆盖 |
| 解决方案 | Text | 仅供人工填写，系统永不覆盖 |
| 状态 | SingleSelect | `待讨论`/`已排期`/`已上线`/`验证中` |
| 迭代周期 | SingleSelect | `Sprint 1`/`Sprint 2`/`Sprint 3+`/`待定` |

**生成规则**：
- 一个 Top 问题 = Tag2 + Tag3 组合。
- 按大租户反馈总数降序排列，取前 20-30 条。
- 首次全量写入。后续每次分析，若问题已存在（通过 Tag2+Tag3 组合识别），仅更新"本期新增数"，**绝不覆盖**人工填写的字段。

## 4. 标签体系使用规则

### 4.1 三层标签的含义

| 层级 | 含义 | 示例 |
|------|------|------|
| **Tag1 问题性质** | 问题本质类型，决定处理路径 | 性能提升 |
| **Tag2 功能模块** | 问题归属的功能/业务域 | 打卡模块 |
| **Tag3 具体问题** | 从用户原话提炼的具体现象 | 定位失败 |

### 4.2 标签的创建与管理
- Tag1 默认 7 类，管理员可在配置中心增删改。
- Tag2/Tag3 由 AI 动态创建，用户也可在多维表格中手动新增。
- 反馈列表引用标签后，**修改标签名称会自动同步到所有引用它的反馈**。

### 4.3 标签缓存
为避免每次打标都查询标签体系，系统采用 **5 分钟内存缓存**机制。

## 5. 核心流程

### 5.1 数据拉取与 AI 打标（每周）

**触发**：定时任务（默认每周一 09:00），或手动通过配置中心按钮触发。

**数据源模式**：
- **API 拉取**：调用配置的接口地址，使用 API Key 和时间范围规则自动拉取。
- **Excel 上传**：用户手动上传 Excel 文件（配置中心上传）。

**流程步骤**：
1. **获取反馈**：根据数据源模式获取反馈数据
2. **去重**：与表格中已有的反馈 ID 对比，过滤重复数据
3. **补充租户名**：查找每条反馈对应的租户名称，新租户自动写入租户信息表
4. **语言翻译**：系统自动检测反馈原文语言，非中文自动翻译
5. **AI 打标**：AI 逐批分析反馈，给出 Tag1/Tag2/Tag3 标签、置信度、是否需要查日志
6. **结果写入表格**：所有结果一次性写入飞书多维表格
7. **发送 Bot 通知**：向配置的飞书群发送周报消息卡片
8. **生成周报文档**：自动创建飞书周报文档

### 5.2 月度分析与标签进化（每月）

**触发**：定时任务（默认每月 1 日 00:00），或手动通过配置中心按钮触发。

**流程**：
1. **标签自进化**：检测并合并相似标签、拆分过大的标签
2. **生成 Top 问题表**：统计每个 Tag2+Tag3 组合的反馈数，按大租户反馈数降序排列
3. **生成会议文档**：创建飞书月报文档
4. **发送 Bot 通知**：向配置的飞书群发送月报消息卡片

## 6. Bot 通知消息内容

### 6.1 周报消息（每周）

卡片内容：
- 标题：【Feelgood 打标周报】年份+第N周
- 本周拉取数量、待审核数量
- Top 5 问题列表
- 评分分布
- 操作按钮：审核标签、完整看板、查看日志平台（有条件显示）
- 警告：待审核 > 100 时显示红色警告

### 6.2 月报消息（每月）

卡片内容：
- 标题：【Feelgood 月度分析】年份+月份
- Top 问题概览（前3-5条）
- 操作按钮：Top 问题表、查看会议文档、可视化仪表盘
- 标签自进化记录

### 6.3 错误通知卡片

当任务执行失败时，自动发送错误通知卡片：
- 任务类型
- 执行时间
- 错误信息
- 建议操作

### 6.4 机器人命令
- `/nps help` — 显示帮助信息
- `/nps status` — 查看当前配置状态
- `/nps tag` — 手动触发打标流程

## 7. 配置中心

配置中心分为三个 Tab 页，右上角有全局操作按钮。

### 7.1 全局操作按钮（右上角）

位于页面标题栏右侧，包含：
- **开始周打标**：手动触发周度数据同步和 AI 打标
- **开始月分析**：手动触发月度分析和标签进化
- **编辑/保存**：切换编辑模式

**编辑模式规则**：
- 默认进入只读模式，所有输入框禁用
- 点击「编辑」后，输入框变为可编辑
- 点击「保存」后，保存所有配置并返回只读模式
- 所有 Tab 的独立保存按钮已移除，统一使用右上角保存

### 7.2 Tab 1：飞书与集成

- 飞书应用凭据（App ID、App Secret）
- 多维表格（新建或绑定已有）
- 数据源配置（API 模式配置）
- Excel 上传
- Webhook 地址展示
- 飞书通知群绑定
- 飞书多维表格管理员配置
- 大租户定义

### 7.3 Tab 2：AI 与标签

- AI 模型选择（预设模型或自定义 API）
- AI API Key 配置
- Tag1 一级标签管理（列表展示，增删改）
- Tag2 初始化预设
- 置信度阈值配置

### 7.4 Tab 3：任务与运营

- 数据拉取周期配置
- 月度分析周期配置
- 日志平台 URL 配置
- 通知群配置
- 表格管理员配置
- 手动触发任务按钮

## 8. 标签自进化规则

每月分析时，AI 自动检查标签体系的合理性：

| 操作 | 条件 | 执行方式 |
|------|------|----------|
| **合并** | 两个同层级标签语义几乎相同 | AI 自动合并，更新所有历史反馈引用 |
| **拆分** | 某 Tag2 下 Tag3 超过 10 个且能明显分成多类 | AI 自动创建新 Tag2，迁移对应 Tag3 |
| **保留** | 使用次数很少的标签 | 不做任何处理 |
