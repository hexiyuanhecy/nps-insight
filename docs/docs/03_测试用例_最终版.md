## 1. 配置中心测试

### 1.1 全局编辑模式

#### TC-001: 默认进入只读模式

**前置条件**：用户打开配置中心页面

**测试步骤**：
1. 进入配置中心页面
2. 观察页面右上角按钮

**预期结果**：
- 所有输入框为 disabled 状态
- 右上角显示「编辑」按钮
- 右上角不显示「保存」按钮

#### TC-002: 点击编辑后进入编辑模式

**前置条件**：用户在只读模式

**测试步骤**：
1. 点击右上角「编辑」按钮
2. 观察输入框状态
3. 观察右上角按钮变化

**预期结果**：
- 所有输入框变为 enabled 状态
- 「编辑」按钮消失
- 「保存」按钮显示
- 所有 Tab 的独立保存按钮不显示

#### TC-003: 保存配置成功

**前置条件**：用户在编辑模式，配置有修改

**测试步骤**：
1. 修改某个配置项
2. 点击右上角「保存」按钮
3. 观察保存过程

**预期结果**：
- 保存按钮显示 loading 状态
- 所有输入框暂时禁用
- 保存成功后显示 Toast 提示「配置已保存」
- 页面返回只读模式
- 输入框恢复 disabled

#### TC-004: 保存配置失败

**前置条件**：用户在编辑模式，配置项有误

**测试步骤**：
1. 修改某个配置项为无效值
2. 点击右上角「保存」按钮
3. 观察保存结果

**预期结果**：
- 保存按钮显示 loading
- 保存失败后显示错误 Toast
- 页面保持编辑模式（不返回只读）
- 输入框恢复可编辑

## 6. 测试环境准备

### 6.1 前置条件

1. 开发服务器运行：`pnpm dev`
2. 飞书应用已创建并配置
3. 测试用多维表格已创建
4. 测试用飞书群已创建

### 6.2 测试数据

- 至少 10 条测试反馈数据
- 包含不同评分（1-5 分）
- 包含不同语言（中文、英文）
- 包含不同租户规模

### 6.3 环境变量

确保以下环境变量已配置：
```bash
FEISHU_APP_ID=cli_xxx
FEISHU_APP_SECRET=xxx
ENCRYPTION_KEY=xxx
CRON_SECRET=xxx
LOG_PLATFORM_URL=http://xxx
NOTIFICATION_CHAT_ID=oc_xxx
```
