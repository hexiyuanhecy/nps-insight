# 配置中心 - PRD 基准清单

**来源文档**：prd-v2.md 第7章
**生成日期**：2026-06-25

---

## PRD-CONFIG-001
- **优先级**：P0
- **功能点**：配置中心整体结构
- **PRD原文**：
  > 配置中心分为三个 Tab 页，部署在飞书应用内，自动获取用户身份。
- **验收标准**：
  - 配置中心分为三个Tab页
  - 部署在飞书应用内
  - 自动获取用户身份，无需手动登录

## PRD-CONFIG-002
- **优先级**：P0
- **功能点**：Tab 1 飞书应用凭据
- **PRD原文**：
  > Tab 1：连接与集成
  > - 飞书应用凭据（App ID、App Secret）
- **验收标准**：
  - Tab 1名称为"连接与集成"
  - 可配置App ID
  - 可配置App Secret
  - App Secret为敏感信息，加密存储

## PRD-CONFIG-003
- **优先级**：P0
- **功能点**：Tab 1 多维表格配置
- **PRD原文**：
  > - 多维表格（新建或绑定已有）
- **验收标准**：
  - 支持新建多维表格
  - 支持绑定已有多维表格
  - 新建表格后自动创建所需的6张数据表
  - 绑定表格后能识别和验证表结构

## PRD-CONFIG-004
- **优先级**：P0
- **功能点**：Tab 1 数据源配置 - API模式
- **PRD原文**：
  > - 数据源配置
  >   - API 模式：接口地址、API Key、查询参数模板（支持 {{start_unix}} 等时间占位符）、时间范围规则
- **验收标准**：
  - 支持API模式配置
  - 可配置接口地址
  - 可配置API Key
  - 可配置查询参数模板
  - 支持 {{start_unix}} 等时间占位符
  - 可配置时间范围规则
  - API Key加密存储

## PRD-CONFIG-005
- **优先级**：P0
- **功能点**：Tab 1 数据源配置 - Excel上传
- **PRD原文**：
  >   - Excel 上传：文件上传区域，上传后自动覆盖 API 模式优先级
- **验收标准**：
  - 支持Excel文件上传
  - 有文件上传区域
  - 上传后Excel模式优先级高于API模式
  - 上传后可触发打标流程

- **PRD原文**：

## PRD-CONFIG-008

- **PRD原文**：
  > Tab 2：AI 与标签
  > - AI 模型（下拉选择预设模型，或自定义 API 地址和模型名，填入 Token）

  - 支持下拉选择预设AI模型

## PRD-CONFIG-009
- **优先级**：P0
- **功能点**：Tab 2 Tag1一级标签管理
- **PRD原文**：
  > - Tag1 一级标签管理（列表展示，可增删改，默认 7 类）
- **验收标准**：
  - 有Tag1一级标签管理功能
  - 列表展示所有Tag1标签
  - 支持新增Tag1
  - 支持修改Tag1
  - 支持删除Tag1
  - 默认有7类标签
  - 标签变更后同步到多维表格Tag1表

- **验收标准**：

## PRD-CONFIG-011
- **优先级**：P0
- **功能点**：Tab 2 打标规则
- **PRD原文**：
  > - 打标规则（置信度阈值，默认 0.8；大租户定义，默认 A4/A5/A6）
- **验收标准**：
  - 可配置置信度阈值
  - 默认值为0.8
  - 可配置大租户定义
  - 默认大租户为A4/A5/A6
  - 低于置信度阈值的反馈标记为"待审核"

## PRD-CONFIG-015

- **PRD原文**：
  > - 通知群（输入飞书群 ID，多个用英文逗号分隔，附"测试发送"按钮）

## PRD-CONFIG-016
- **优先级**：P0
- **功能点**：Tab 3 表格管理员
- **PRD原文**：
  > - 表格管理员（输入飞书用户 ID，多个用英文逗号分隔，仅所有者可修改）
- **验收标准**：
  - 可配置表格管理员
  - 输入飞书用户ID
  - 支持多个管理员，用英文逗号分隔
  - 仅配置所有者可修改管理员列表
  - 管理员会被添加为多维表格的协作者（管理员权限）
