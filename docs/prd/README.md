## 使用说明

1. **开发前**：对照本清单确认需求范围，避免遗漏
2. **开发中**：每完成一个功能点标记为已实现
3. **测试时**：按验收标准逐项验证
4. **迭代时**：PRD更新后同步更新本清单，保持版本一致
