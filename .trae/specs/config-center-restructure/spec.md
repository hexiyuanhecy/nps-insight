# 配置中心结构重组 - Product Requirement Document

## Overview
- **Summary**: 重新组织配置中心的 Tab 结构和配置项顺序，将配置项按业务领域重新归类为三大模块：飞书配置、数据源、打标与分析配置，使用户能更直观地找到相关配置。
- **Purpose**: 解决当前配置项分类不够清晰的问题，按照用户心智模型重新组织配置结构，提升配置中心的易用性和可理解性。
- **Target Users**: NPS Insight 系统管理员、配置操作人员

## Goals
- 将配置中心从 3 个 Tab（飞书与集成 / AI 与标签 / 任务与运营）重组为 3 个新 Tab（飞书配置 / 数据源 / 打标与分析配置）
- 飞书配置模块集中管理所有飞书相关配置（应用、通知群、多维表格管理员、大租户定义、表格绑定/新建）
- 数据源模块集中管理反馈数据来源配置（API、Excel 导入、日志平台）
- 打标与分析配置模块集中管理 AI 模型、标签体系、置信度等智能分析相关配置
- 多维表格绑定/新建时自动使用前面配置的管理员信息
- 保持所有现有功能不变，仅调整结构和顺序

## Non-Goals (Out of Scope)
- 不新增或删除任何配置项
- 不修改配置的存储结构和 API 接口
- 不修改打标逻辑和分析算法
- 不修改定时任务的执行逻辑
- 不修改飞书 Bot 响应逻辑

## Background & Context
当前配置中心分为「飞书与集成」「AI 与标签」「任务与运营」三个 Tab，但用户反馈配置项分类不够直观：
- 飞书相关配置分散在多个 Tab 中（应用在飞书与集成、通知群在任务与运营）
- 大租户定义放在打标规则里不够合理
- 数据源配置和飞书配置混在一起
- 用户难以快速找到自己想要的配置项

本次调整按照用户的业务心智模型，将配置重新归类为三大模块。

## Functional Requirements

### FR-1: 飞书配置 Tab
系统 SHALL 提供「飞书配置」Tab，集中管理所有飞书相关配置项。

#### 飞书应用绑定
- **WHEN** 用户进入飞书配置 Tab
- **THEN** 第一个配置模块为「飞书应用绑定」
- **AND** 包含 App ID 和 App Secret 配置
- **AND** 包含「测试飞书连接」按钮和「保存配置」按钮

#### 飞书通知群绑定
- **WHEN** 用户查看飞书配置 Tab
- **THEN** 第二个配置模块为「飞书通知群绑定」
- **AND** 包含通知群聊 ID（chatIds）配置
- **AND** 包含「测试消息发送」按钮和「保存配置」按钮

#### 飞书多维表格管理员配置
- **WHEN** 用户查看飞书配置 Tab
- **THEN** 第三个配置模块为「飞书多维表格管理员配置」
- **AND** 包含管理员用户 ID（adminUserIds）配置
- **AND** 说明管理员将被添加为新建多维表格的协作者

#### 大租户定义
- **WHEN** 用户查看飞书配置 Tab
- **THEN** 第四个配置模块为「大租户定义」
- **AND** 包含大租户级别选择（A1-A6 多选）
- **AND** 说明大租户的反馈将采用更高的权重或优先级

#### 飞书表格绑定/新建
- **WHEN** 用户查看飞书配置 Tab
- **THEN** 第五个配置模块为「飞书多维表格绑定/新建」
- **AND** 展示当前已绑定状态和表格链接
- **AND** 提供「创建新表格」和「绑定已有表格」两个选项
- **AND** 创建/绑定表格时，自动将前面配置的「多维表格管理员」添加为协作者
- **AND** 包含「保存配置」按钮

### FR-2: 数据源 Tab
系统 SHALL 提供「数据源」Tab，集中管理所有反馈数据来源相关配置。

#### 反馈来源 - API
- **WHEN** 用户进入数据源 Tab
- **THEN** 第一个配置模块为「反馈来源 - API」
- **AND** 包含 API 地址、API Key、查询参数、时间规则等配置
- **AND** 包含「测试连接」按钮和「保存配置」按钮

#### 反馈来源 - Excel 导入
- **WHEN** 用户查看数据源 Tab
- **THEN** 第二个配置模块为「反馈来源 - Excel 导入」
- **AND** 包含 Excel 文件上传功能
- **AND** 包含导入说明和模板下载指引
- **AND** 包含「导入数据」按钮

#### 其他反馈来源
- **WHEN** 用户查看数据源 Tab
- **THEN** 展示其他可用的反馈来源配置（如 Webhook 接收地址等）

#### 日志反馈平台配置
- **WHEN** 用户查看数据源 Tab
- **THEN** 最后一个配置模块为「日志反馈平台配置」
- **AND** 包含日志平台 URL 模板配置
- **AND** 展示系统内部 Mock 日志平台链接供预览
- **AND** 包含「保存配置」按钮

### FR-3: 打标与分析配置 Tab
系统 SHALL 提供「打标与分析配置」Tab，集中管理 AI 打标和分析相关配置。

#### AI 模型选择
- **WHEN** 用户进入打标与分析配置 Tab
- **THEN** 第一个配置模块为「AI 模型选择」
- **AND** 包含热门模型厂商下拉选择
- **AND** 包含模型版本下拉选择
- **AND** 包含 API Key 和 Base URL 配置
- **AND** 包含「测试连接」按钮和「保存配置」按钮

#### Tag1 / Tag2 标签配置
- **WHEN** 用户查看打标与分析配置 Tab
- **THEN** 第二个配置模块为「标签体系配置」
- **AND** 包含 Tag1 一级标签配置（7 个默认标签，可编辑定义）
- **AND** 包含 Tag2 二级标签预设配置
- **AND** 包含标签体系说明文档
- **AND** Tag1 修改后提供「立即重新打标历史数据」按钮
- **AND** 包含「保存配置」按钮

#### 置信度阈值
- **WHEN** 用户查看打标与分析配置 Tab
- **THEN** 第三个配置模块为「置信度阈值」
- **AND** 包含置信度阈值滑块/输入框
- **AND** 包含置信度定义说明
- **AND** 包含「保存配置」按钮

#### 定时任务周期
- **WHEN** 用户查看打标与分析配置 Tab
- **THEN** 第四个配置模块为「定时任务周期」
- **AND** 包含数据拉取周期配置（自然语言选择器）
- **AND** 包含月度分析周期配置（自然语言选择器）
- **AND** 包含开发模式开关
- **AND** 包含「立即同步」和「立即分析」按钮
- **AND** 包含「保存配置」按钮

### FR-4: 多维表格创建/绑定时使用管理员信息
系统 SHALL 在创建或绑定多维表格时，自动将管理员配置添加为表格协作者。

#### 场景：创建新表格
- **WHEN** 用户点击「创建新表格」按钮
- **THEN** 系统应读取「飞书多维表格管理员配置」中的管理员用户 ID
- **AND** 创建表格后自动将这些管理员添加为表格协作者
- **AND** 管理员应拥有「可编辑」或更高权限

#### 场景：绑定已有表格
- **WHEN** 用户绑定已有多维表格
- **THEN** 系统应读取「飞书多维表格管理员配置」中的管理员用户 ID
- **AND** 尝试将管理员添加为表格协作者
- **AND** 若权限不足，应提示用户手动添加

## Non-Functional Requirements

- **NFR-1**: 所有配置项的功能逻辑保持不变，仅调整展示顺序和所属 Tab
- **NFR-2**: 配置保存和读取的 API 接口保持向后兼容
- **NFR-3**: UI 交互体验保持一致（Toast 提示、按钮样式等）
- **NFR-4**: 页面加载性能不应有明显下降

## Constraints
- **Technical**: Next.js 14 + TypeScript + TailwindCSS
- **Business**: 不影响现有用户的配置数据
- **Dependencies**: 依赖现有的飞书 SDK、存储适配器、通知适配器

## Assumptions
- 用户更习惯按「飞书 → 数据源 → 打标分析」的顺序配置系统
- 大租户定义与飞书多维表格权限管理关系更紧密
- 定时任务属于打标与分析流程的一部分
- 管理员配置主要用于多维表格权限管理

## Acceptance Criteria

### AC-1: 飞书配置 Tab 结构正确
- **Given**: 用户已登录并进入配置中心
- **When**: 用户点击「飞书配置」Tab
- **Then**: 页面按顺序展示以下 5 个模块：
  1. 飞书应用绑定
  2. 飞书通知群绑定
  3. 飞书多维表格管理员配置
  4. 大租户定义
  5. 飞书多维表格绑定/新建
- **Verification**: `human-judgment`
- **Notes**: 每个模块都有独立的保存按钮

### AC-2: 数据源 Tab 结构正确
- **Given**: 用户已登录并进入配置中心
- **When**: 用户点击「数据源」Tab
- **Then**: 页面按顺序展示反馈来源配置（API、Excel 导入、其他）和日志平台配置
- **Verification**: `human-judgment`

### AC-3: 打标与分析配置 Tab 结构正确
- **Given**: 用户已登录并进入配置中心
- **When**: 用户点击「打标与分析配置」Tab
- **Then**: 页面按顺序展示：
  1. AI 模型选择
  2. 标签体系配置（Tag1 / Tag2）
  3. 置信度阈值
  4. 定时任务周期
- **Verification**: `human-judgment`

### AC-4: 创建表格时自动添加管理员
- **Given**: 用户已配置飞书多维表格管理员（adminUserIds）
- **When**: 用户点击「创建新表格」并成功创建
- **Then**: 新建的多维表格应已将管理员用户添加为协作者
- **Verification**: `programmatic`
- **Notes**: 可通过飞书 API 验证协作者列表

### AC-5: 所有配置项功能正常
- **Given**: 配置中心结构重组完成
- **When**: 用户修改任意配置项并保存
- **Then**: 配置应正确保存到数据库
- **And** 刷新页面后配置应正确回显
- **Verification**: `programmatic`

### AC-6: 配置 API 向后兼容
- **Given**: 配置中心结构重组完成
- **When**: 旧版客户端调用配置 API
- **Then**: API 应能正常响应，数据格式不变
- **Verification**: `programmatic`
