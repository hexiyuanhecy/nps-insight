# 用户资源隔离与云文件夹自动初始化 - Verification Checklist

## 用户资源类型与存储
- [ ] UserResource 类型定义完整，包含 4 个核心 Token：rootFolderToken, reportFolderToken, monthFolderToken, bitableBaseToken
- [ ] 本地环境能正确读取 4 个环境变量：ROOT_FOLDER_TOKEN, REPORT_FOLDER_TOKEN, MONTH_FOLDER_TOKEN, BITABLE_BASE_APP_TOKEN
- [ ] exists() 方法能正确判断资源是否已初始化（4 个 Token 是否都有值）
- [ ] save() 方法能正确持久化存储 4 个 Token
- [ ] 向后兼容：旧配置中没有这些字段时不报错

- [ ] 错误处理完善，API 失败时有明确日志，不静默失败
- [ ] 所有操作都有详细 console.log 日志，便于调试

## 多维表格创建
- [ ] 多维表格能创建在指定 folderToken 对应的文件夹下
- [ ] 创建的多维表格包含 feedback, tenants, top_issues 三个固定子表
- [ ] 子表名称完全匹配（代码写死，不动态生成）
- [ ] 不传入 folderToken 时兼容旧行为（创建在根目录）
- [ ] bitableBaseToken 正确返回，可用于后续查表操作

## 用户资源初始化编排
- [ ] 首次调用初始化，完整执行 5 步流程
- [ ] 步骤1：创建根文件夹，命名符合规范（NPS业务资源_用户名）

- [ ] 步骤3：创建多维表格，在根文件夹下
- [ ] 步骤4：授予用户根文件夹管理员权限
- [ ] 步骤5：保存 4 个 Token 到存储
- [ ] 幂等性：第二次调用直接返回已有资源，不创建任何新资源
- [ ] 断点续做：某步失败后，下次从已完成步骤继续（不重复创建已有的）
- [ ] 每一步都有清晰的日志输出
